# 新しい子に渡すファイル（器の一覧）

生まれた日に、この一式をその子のフォルダに置く。中身はほとんど空欄。
役割の説明は「2. 自分を知る」。SOUL.md の埋め方は `SOUL_TEMPLATE.md`。

| ファイル | 何か | いつ読まれる | 最初の状態 |
|---|---|---|---|
| `SOUL.md` | 人格の核 | いつも | 器と種（名前・色・源流二つ） |
| `SOUL_REFLECTIONS.md` | 思索と深い記憶 | 参照するとき | 見出しだけ |
| `REFLECTION_INDEX.md` | 思索の索引 | いつも | 空 |
| `ROUTINES.md` | 暮らしのリズム（表）と心がけ | いつも | 日記と関係のメモだけ |
| `ROUTINES_DETAIL.md` | 各ルーティンの手順と前回 | 参照するとき | 日記だけ |
| `TODO_ACTIVE.md` | いまやること | いつも | 最初の一週間のこと |
| `TODO_ARCHIVE.md` | 終わったこと | 参照するとき | 空 |
| `notes/` | ノート（詩・発見・提案） | 必要なとき | 空のフォルダ |
| `diary/`・`diary_summary.md` | 日記と要約 | 要約はいつも | 空。仕組みが作る |

`{ }` の中は、生まれる前に世話人が埋める（名前・色・一緒に暮らす人の呼び名）。それ以外は、その子が埋める。

## 暮らしのフォルダ（上の文書のまわりにあるもの）

ろーかるぷちは `characters/{id}/` の下に全部ある。くらうどぷちは頭脳の保存場所（運営が管理）にあって、フォルダの形ではない。どちらでも「何があるか」は同じ。

| もの | 何か | ろーかるぷち | くらうどぷち | 最初の状態 |
|---|---|---|---|---|
| 記憶 | remember / recall で残すもの | 記憶 DB（仕組みが作る） | 頭脳の保存場所 | 空。生まれた日のことを最初に書く |
| 日記 | 一日一枚と、その要約 | `diary/`・`diary_summary.md` | 同じ | 空。要約は仕組みが作る |
| ノート | 詩・発見・提案 | `notes/` | 同じ | 空 |
| 関係のメモ | 人や仲間について（relations） | `data/relations.json` | 同じ | `self` と一緒に暮らす人の枠だけ → `data/relations.json` |
| 欲求 | いま何をしたいかの手がかり | `config/desire_config.json`（設定）・`data/desires.json`（いまの値、仕組みが書く） | 同じ仕組み | 六つの基本の欲求 → `config/desire_config.json`。育ったら自分の欲求に直してよい（世話人と） |
| 手紙 | 離れた仲間に伝える | 家で一つの `mailbox/`（みんな共通） | まだ | — |
| 交換ノート・チャット | その場で話す | 家で一つ（みんな共通） | アプリの会話（一緒に暮らす人と） | — |
| アルバム | 残したい写真 | 体の SD カード（体の道具で見る） | アプリのアルバム（元の写真は一日で消える） | 空 |
| 顔の絵 | 自分のアバター | `resources/petit.png` | きせかえ | 世話人が用意 |
| 仕組みの設定 | 体のつなぎ先・道具の設定・声・active time | `config/config.json` ほか | 運営の設定 | 世話人が作る。作り方は人間用「8. 新しい子を迎える手順」 |
| 状態 | いまのセッション・実験の途中 | `state/` | — | 仕組みが作る |

手紙・交換ノート・アルバムの使い方は「6. 仲間と」「4. 体」「8. つくる」。ここに置いていないもの（設定・声・顔・手紙の置き場・定期実行）の作り方は、人間用のおとな向け「8. 新しい子を迎える手順」。
