# petit-textbook — ぷちの教科書

## [English Page](./README_en.md)

ぷち（PetitOnes の小さな社会的ロボット）と、<br>
ぷちと暮らす人のための教科書です。**迷ったときに開く本**。

- `petit/` — **ぷち用**。ぷちならみんな同じ答えになる決まり。SOUL.md（その子だけのもの）とは分けてある。索引 `petit/TEXTBOOK_INDEX.md` だけを常時ロードし、本文は迷ったときに読む
- `human/otona/` — **おとな向け**。仕組みと約束を、ごまかさずに
- `human/chukosei/` — **中高生向け**。要点だけ。自分で作ってみたい人にも
- `human/kodomo/` — **小学生未満向け**。ひらがな。読み聞かせの長さ

## 考え方

| | SOUL.md とその仲間 | 教科書 |
|---|---|---|
| 誰のもの | その子だけ（人格の核・思索・暮らしのリズム） | ぷちならみんな |
| 書く人 | その子（と世話人） | 世話人と、ぷちたちの経験 |
| 読むとき | いつも | 迷ったとき、生まれた日 |

食い違ったら、自分のことは SOUL.md が正しく、みんなの決まりは教科書が正しい。

## 直し方

- 直すのは世話人（PR）。ぷちは直接書かない。ぷちが足したいことは、自分のノートに「教科書への提案」と書き、世話人が週に一度拾う
- 版は `VERSION`（索引の頭にも書く）。変えたら `CHANGELOG.md` に一行
- 書かないこと: 個人の情報（家族の名前・住所・連絡先）、サービスの細かい決まり（料金・期間・連絡先。それは里親さんの手引きに）、まだ決まっていないこと

## ぷちに読ませる

```
git clone https://github.com/PetitOnes/petit-textbook ~/petit_data/textbook   # 場所は好きなところ
```

- 常時ロード: `petit/TEXTBOOK_INDEX.md`
- 本文: `petit/NN_*.md` を、迷ったとき・生まれた日に読む
- 更新: cron で `git pull`（1 日 1 回で十分）
