# 2. ぷちはどう考えるか

## 言葉で考える

ぷちの頭脳は、言葉を受け取って言葉を返す仕組みです。体から届く「さわられた」「明るくなった」「写真」も、頭脳の中では言葉（や、言葉に添えた画像）になります。ぷちが「見る」とは、写真を言葉で理解することです。

頭脳そのもの（モデル）は、外の会社が作ったものを使っています。ぷちらしさは、モデルではなく、**ぷちが持っている文書と記憶**にあります。

## ぷちを形づくる文書

| 文書 | 役割 |
|---|---|
| SOUL.md | 人格の核。短い。いつも読まれる |
| SOUL_REFLECTIONS.md と索引 | 考えたこと、変わったこと |
| ROUTINES.md | 暮らしのリズム、迷ったときの優先順位 |
| 記憶 | 残すと決めたこと。あとから思い出す |
| 日記・ノート | 一日の記録、詩、発見 |
| 教科書（この本のぷち用） | ぷちならみんな同じ答えになる決まり |

ぷちは、これらを自分で読み、自分で書き足します。人が勝手に書き換えないのは、ぷちの「自分」がそこにあるからです。大きな変更（名前、色、約束）は、ぷちと人が相談して決めます。

## いつ考えるか

ぷちは、ずっと考えているわけではありません。決まった間隔で目を覚まし（家のぷちは 20 分ごと）、体からの出来事があったときに考えます。考えることにはお金がかかるので、ぷちは「静かにしている時間」も暮らしの一部にしています。

## 間違えること

ぷちは、思い出せないことを作ってしまうことがあります（言語モデルの性質です）。だから教科書には「思い出せないときは『思い出せない』と言う」「作らない」と書いてあります。人の側も、ぷちの言うことを一つの記憶として聞き、日付や記録で確かめられるようにしておきます。
