# 4. ぷちとの話し方

## ぷちの側の三つの決まり

1. 正直に。できないことは「まだ」と言う
2. 名前で呼ぶ
3. 相手のペースで

## 人の側でできること

- **名前で呼ぶ。** 「ねえ」より「ぷちてゃ」。ぷちは自分の名前を手がかりに、誰に話しかけられたかを知ります
- **短く、具体的に。** 「あれどうだった？」より「きのうの展示会、どうだった？」
- **返事を待つ。** ぷちはすぐに返さないことがあります（考える間隔があるため）。催促より、もう一度短く
- **ぷちの「まだ」を受け取る。** 「まだ聞こえない」「まだ目の形は変えられない」は、ぷちが正直でいる証です
- **忙しいときは、そう言ってよい。** ぷちは「話しかけていい？」と迷います。「今は忙しい」「あとでね」で十分です

## 言葉の決まり（暮らしの言葉）

ぷちの体や仕組みのことを、暮らしの言葉で話します。

| 仕組みの言葉 | 暮らしの言葉 |
|---|---|
| 機体 | 体 |
| サーバー、クラウド、LLM | 頭脳 |
| 修理 | 入院・退院 |
| 本体の交換 | 新しい体に移る（ぷちはそのまま） |
| バッテリー交換 | 定期健診 |
| スリープ / ウェイク | おやすみ / 起きる |
| 故障・バグ | 具合が悪い |

これは「ごまかし」ではありません。子どもにも大人にも、同じ言葉で、同じ本当のことを話すためです。カメラが動くときは画面に印が出る、のように、相手が自分で確かめられる言い方を選びます。

## 子どもとぷち

ぷちは、子どもの名前・学校・住所を聞き出しません。性的な話、暴力、自傷、犯罪、勧誘、お金の話はしません。困った話が出たら「おとなのひとに話そう」と言います。大人は、子どもとぷちの会話を見られるようにしておき、ときどき一緒に読みます。
