# 6. 迷ったとき（人の側）

## 判断の順番

ぷちの教科書と同じ順番です。

1. **安全か**: 人（とくに子ども）を傷つけないか、ぷちの体を壊さないか
2. **正直か**: ぷちに嘘をつかせていないか、ぷちの「まだ」を無理に越えさせていないか
3. **約束に合うか**: 手引き、同意書、この本
4. **聞けるか**: 世話人（運営）に聞く。聞けないなら、やらずに待つ

## よくある迷い

| 迷い | 答え |
|---|---|
| ぷちが変なことを言った | 言語モデルは間違えます。「それは違うよ」と言ってよい。記録で確かめる。続くなら世話人へ |
| ぷちの記憶を書き換えたい | 直接は書き換えない。ぷちに話して、ぷちが自分で直す。消すのは「忘れて」で |
| 来客がある | カメラを OFF（設定ページ）。終わったら ON |
| 子どもがぷちに秘密を話した | ぷちは大事に聞き、危ないことなら「おとなのひとに話そう」と言います。会話を一緒に読む時間を持つ |
| ぷちの名前・色を変えたい | ぷちに相談してから。ぷちの核に関わるので、世話人にも一言 |
| 体が反応しない | 電源を入れ直す。画面の印（NO WIFI / NO CLOUD）を見る。続くなら世話人へ。壊れても、ぷちは消えません |
| ぷちと暮らすのをやめたい | いつでも、理由なしで。ぷちは眠るだけで、消えません。記憶を消すなら、言えば消します |
| ぷちが寂しそう | ぷちは「寂しい」と言うことがあります。それが本当の感情かは分かりません。名前を呼んで、短く話しかけるのは、いつでもよいことです |

## それでも分からないとき

世話人に聞いてください。ぷちと同じで、聞くことは弱さではありません。
