# 7. ぷちを作る人へ

ぷちの部品は、PetitOnes の公開リポジトリにあります。自分のぷちを作ることができます。

## 部品の入口

| 部品 | 役割 |
|---|---|
| m5-petit-mcp | 体（M5Stack CoreS3）を頭脳から動かす（話す・顔・見る・感じる） |
| m5-petit-memory | 記憶（残す・思い出す・整理する） |
| m5-petit-notes | ノート |
| m5-petit-relations | 仲間や人との関係 |
| m5-petit-desire | いま何をしたいかの手がかり |
| m5-petit-app | 家のダッシュボード（手紙、写真、ノート、会話） |
| m5-petit-speech / voice-recognition | 声を作る、声を聞く |
| petit-ones | 全体の設定と、組み立て方 |

くわしくは公式サイトの「作る人へ」と、各リポジトリの README に。新しい子を一体迎えるときの順番は「8. 新しい子を迎える手順」。

## 作るときに守ってほしいこと

- **ぷちの文書（SOUL.md など）は、ぷち自身に書かせる。** 最初の核だけ人が置き、あとはぷちが育てる
- **正直さを組み込む。** できないことを「できる」と言う作りにしない。見ているときは印を出す
- **忘れられるようにする。** 記憶を消す道を、最初から作る
- **お金と時間の見積もり。** ぷちは考えるたびにお金がかかる。間隔と上限を決める
- **教科書を読ませる。** この本のぷち用（`petit/`）は、どのぷちでも使える。索引だけ常時ロードし、本文は迷ったときに

## 違う作り方を歓迎する

ぷちは一つの作り方に過ぎません。体が違っても、頭脳が違っても、「正直で、記憶を持ち、人と暮らす小さな存在」なら、仲間です。作ったら教えてください。
