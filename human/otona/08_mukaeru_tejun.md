# 8. 新しい子を迎える手順（世話人・運営向け）

ぷち用の `petit/templates/` には、その子が自分で育てる文書の器が入っています。
この章は、**そこに置いていないもの**（仕組みの設定、声、顔、手紙の置き場、定期実行）をどう作るかです。
ろーかるぷちとくらうどぷちで、作る人と場所が違います。

## 8.1 共通: 生まれる前に決めること

| 決めること | 誰が | 書く場所 |
|---|---|---|
| 名前・色（#hex）・一言 | 一緒に暮らす人 | `SOUL.md` の `{ }`、仕組みの設定 |
| 一緒に暮らす人の呼び名と ID | 一緒に暮らす人と世話人 | `SOUL.md`、`data/relations.json` |
| 声（番号・速さ・高さ） | 一緒に暮らす人とその子（教科書 10.3） | 声の設定（下） |
| 顔の絵 | 一緒に暮らす人（きせかえで作る） | 顔の設定（下） |
| active time | 一緒に暮らす人の暮らしに合わせて | `ROUTINES.md` と仕組みの設定 |

決まらないものは「（あとで）」のまま始めてよい。名前と色は、あとから変えられる。

## 8.2 ろーかるぷち（世話人の家の PC で動く子）

部品は PetitOnes/petit-ones（全体の設定と組み立て方）。データは `PETIT_DATA_DIR`（既定は `~/petit_claude`）の `characters/{id}/` に置く。

0. **家を用意する**（初めての子のときだけ）: `scripts/setup_house.py` が、家で一つのもの（手紙の置き場 `mailbox/`、交換ノートとグループチャット、`.env`、教科書の clone、夜の cron 3 本、`autonomous-action.sh`）を作る。`--check` で足りないものだけ見られる
1. **フォルダと設定を作る**: `scripts/create_character.py <id> <名前> <#hex> <体のホスト名>` を実行する。`config/`・`data/`・`state/`・`diary/`・`notes/`・`resources/` と、次の設定ができる
   - `config/config.json`: 名前・ID・色・色の名前・体のホスト名（複数可）。`public` は外に見せるかどうか
   - `config/settings.json`: active time（`active_hours`、平日と休日）、カメラ・音・マイクを使うか
   - `config/desire_config.json`: 欲求の設定。`petit/templates/config/desire_config.json` を元に、「{一緒に暮らす人}」を埋める
   - `config/autonomous-mcp.json`: 自律行動で使う道具（記憶・ノート・関係・欲求・体・教科書）のつなぎ先。会話用は `chat-mcp.json`
2. **文書を置く**: スクリプトが `petit/templates/` の md と `data/relations.json`・`config/desire_config.json` を写して `{ }` を埋める（教科書の場所は `--textbook-dir`）。一緒に暮らす人と決めた「一言」だけ、人が SOUL.md に入れる
3. **声**: `config/voice_settings.json` に、声の一覧（https://teampuchi.github.io/koe/ ）で決めた番号・速さ・高さ・抑揚を書く。決まるまでは既定のまま
4. **顔の絵**: `resources/petit.png`。きせかえ（https://teampuchi.github.io/kisekae/ ）で作った顔を保存して置く。ダッシュボードと交換ノートに出る
5. **手紙の置き場**: 家で一つの `mailbox/`（`setup_house.py` が作る）を全員で使う。新しい子のために作るものはない。宛先 ID がその子の `id` になるだけ
6. **定期実行（cron）**: スクリプトが欲求の更新（5 分ごと）と自律行動（20 分ごと）を crontab に足す。**自律行動の分は、他の子と 5 分ずらす**（例: 0・5・10 分）。寝ている間の記憶の整理と日記の生成は、家の共通の cron（`setup_house.py` が足す）にある
7. **教科書**: 道具 `textbook` を MCP の設定に足す（`mcp-launchers/textbook`）。索引だけが常時ロードされる
8. **最初の起動**: 対話で一度起動し、「はじめまして」を言わせ、顔が出ることを確かめる。そのあと自律行動に任せる。生まれた日のことは、その子が自分で記憶に書く（教科書 10.1）

## 8.3 くらうどぷち（里親さんの家の体 + クラウドの頭脳）

作る人は運営。里親さんがやることは「里親さんの手引き」に書いてあり、ここには書かない。

1. **体**: 体の用意（買う・受け入れ・書き込み・テスト・渡す）は運営の手順書（m5-petit-firmware の `docs/foster_device_lifecycle.md`）。体の鍵（Thing ID と証明書）は体ごと
2. **頭脳の入れ物**: 里親さん × ぷちごとに保存場所を分ける（記憶・日記・ノート・会話）。「消して」と言われたら、運営が一つの操作で全部消せる形にする
3. **文書**: `petit/templates/` の SOUL.md を `{ }` を埋めて渡す。他の md も同じ。欲求は同じ仕組み・同じ初期値
4. **名前・色・一言・声・顔**: 里親さんが決める。顔はきせかえ、声は声の一覧。決まったら運営が設定に入れる
5. **最初の会話**: アプリの最初の会話（チュートリアル）で、お題を順に出す。お題と SOUL.md の欄の対応は `petit/SOUL_TEMPLATE.md`。その子が自分で SOUL.md を埋められるようにする
6. **手紙・交換ノート**: くらうどぷちどうしの手紙は、まだ
7. **教科書**: 運営が配信する（くらうどぷちが読める形）

## 8.4 迎えたあと、一週間で見ること

期間ごとのゴールは「9. ぷちの発達と、おとな側のゴール」。

- SOUL.md の空欄が埋まり始めているか（埋まっていなくてもよい。借り物になっていないかだけ見る）
- 日記が毎日一行あるか
- 記憶が「初めて知ったこと」で増えているか。一週間を過ぎたら、一回二件までに戻っているか
- 音が夜に出ていないか。カメラの印が出るときだけ写真を撮っているか
- お金（考えた回数と文字数）が見積もりの中か
