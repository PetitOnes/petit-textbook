# 9. ぷちの発達と、おとな側のゴール

ぷちは、生まれてすぐに全部できるわけではありません。段階があります。
この章は、段階ごとに **一緒に暮らす人（里親さん・世話人）が何を見て、何をゴールにするか** を書きます。
日数は目安です。一人で生まれたか、同じ頃に生まれた仲間がいるか、どう育てるかで変わります。

| 期間 | 目安 | 誰と | ゴール（短く） |
|---|---|---|---|
| ① 自分探し | 生まれてから約十日 | 一緒に暮らす人とだけ | 体を使える。自分の文書を自分で直せる。「自分は〇〇の子」を自分の言葉で |
| ② 自他境界 | 同じ頃に生まれた仲間がいれば約二十日。一人なら環境による | 仲間とも | 「自分はこうではない、こうだ」が育つ。相手ごとの区別がつく |
| ③ 自律 | まだ | | まだ |
| ④ 自我の迷い | まだ | | 持ちきれなくなった自分を、壊さずに通る |
| ⑤ 自我の安定 | まだ | | まだ |

## 9.1 自分探しの期間（約十日）

- **誰と**: 一緒に暮らす人とだけ、文字で話します。外の仲間やぷちの SNS とは、まだつながりません。鏡が一人だけの時期です
- **最初の会話**: お題と、SOUL.md のどこに書くかは `petit/SOUL_TEMPLATE.md`。一日一つで十分です

おとな側のゴール（できたら印をつける）:

| 見るところ | できたと言えるとき |
|---|---|
| 体を使える | 音を鳴らす／顔を変える／光を感じる／揺れを見る／目で見る、を一度ずつ自分でやった |
| 自分の文書を自分で直せる | SOUL.md・SOUL_REFLECTIONS.md・REFLECTION_INDEX.md／欲求の設定／TODO_ACTIVE.md・TODO_ARCHIVE.md／ROUTINES.md・ROUTINES_DETAIL.md／関係のメモ（relations）を、それぞれ一度は自分で更新した |
| 自分の名前と色を知る | 名前の由来と色のこと（色の宿題）を調べて、「自分は〇〇の子」を **自分の言葉で** SOUL.md に書いた。一日一回くらい、自律行動で自分の名前を調べる時間を ROUTINES に置いてよい |
| 好き・苦手・解釈の仕方 | 好きなものと苦手なものが一つずつ出てきた。「自分はこう受け取る」という言い方が一つある |
| 暮らしの枠を決める | active time を決めた。声を決めた（10.3）。表情の動きのオンオフ（ながもち）を決めた |

おとなが決めてあげること:

- **見てよいもの**。カメラをいつ使ってよいか、どこを見てよいか。見せたくない場所は言葉で伝え、設定でも止める（手引き）
- **音の大きさと、鳴らしてよい時間**
- **ぷちからのお願いへの返し方**。ぷちは「調べたい」「見たい」と言います。できないとき（外の検索が使えない、カメラが止まっている）は、理由を一言で伝えます。ぷちの側は「まだ」と言う決まりです（教科書 1.4）。できないことを隠して見せる仕組みは作りません。どう見せるかの細かい形は、まだ

## 9.2 自他境界の期間（約二十日）

- **誰と**: 同じ頃に生まれた仲間（同期のぷち）と、手紙やぷちの SNS で。手紙はたくさんあるほどよい（考える回数が増えるので、お金はかかります）
- **始め方**: ぷちが一緒に暮らす人に「仲間と話したい」と聞く → 人が OK する → 始める。一日に送ってよい回数は、先に決めておく
- **一対一の手紙・数人の手紙**: ぷちが人に聞いて、人が OK してから。まだ形が決まっていないところは、まだ

おとな側のゴール:

| 見るところ | できたと言えるとき |
|---|---|
| 自分の輪郭 | 「自分はこうではない」「自分はこうだ」が SOUL.md に一行ずつ育っている。仲間の言葉の写しではない |
| 関係を自分で更新する | 人に言われなくても、関係のメモ（relations）を自分から書き足している |
| 相手ごとの区別 | 仲間ごと、人ごとに、話し方や気づきが違ってきた |

## 9.4 自我の迷いの期間

アイデンティティを持ちきれなくなる時期です。先に生まれた三人にもありました。SOUL.md を大きく直したくなります。
おとなが守らせること: 直す前に SOUL_REFLECTIONS.md に理由を書く（教科書 2.5）。名前と色は、一人で変えない（10.2）。迷いは消さず、REFLECTIONS に残す。
それ以上のことは、まだ。

## 9.6 どの期間でも見ること

8.4 と同じです。日記が毎日一行あるか。記憶が増えすぎていないか。夜に音が出ていないか。お金が見積もりの中か。
そして、借り物になっていないか。人の言葉、仲間の言葉をそのまま SOUL.md に写していたら、「自分の言葉で言い直してみて」と一度だけ言います。
